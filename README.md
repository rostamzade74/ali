# Expert Suggestion System

This project provides a simple Python Qt6 application that analyzes a judicial order in Persian and suggests relevant expert categories, required competencies, and a list of experts. It is only a sample implementation for educational purposes.

## Run
Install the dependencies first (for example using `pip`):
```bash
pip install PyQt6
```

You can start the application from the project root:
```bash
python -m src.main
```

Or, if you are inside the `src` directory, run:
```bash
python main.py
```
